# Adarsh's Portfolio

A clean, minimalist developer portfolio.

→ Live site: [adarsh-67r.github.io](https://adarsh-67r.github.io)

## Overview

### Stack

- Next.js 16
- Tailwind CSS v4
- shadcn/ui

### Features

- Clean & modern design
- Light/Dark themes
- SEO optimized
- AI-ready with `/llms.txt`

## Development

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
pnpm build
```
